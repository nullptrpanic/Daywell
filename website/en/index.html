Daywell Support

Use Daywell to schedule screen breaks, focus on one app, and log workout sets with a rest timer.

Contact the developer ↗ Common questions ↓

For iPhone and iPad · Requires iOS or iPadOS 17 or later

Set up your first screen break

  1. Set up Screen Time

    Open Daywell's Settings tab. Tap Continue in the Screen Time card, then choose whether to allow access in the system prompt.

  2. Choose what to restrict

    In Sleep, choose apps, categories, or websites to restrict. Open Settings → Allowed Apps to keep essential apps available.

  3. Schedule a block

    Choose start and end times and repeat days. Enable the block and save it. If the current time is inside the block, restrictions start once it has saved.

Common Questions

Why aren't apps restricted during my block?

Check that Screen Time is authorized, the apps are selected, and the block is enabled for the current time and repeat day. A block that crosses midnight is scheduled on the day it starts.

Allowed apps stay available, and a temporary pass pauses the restrictions covered by that pass. If Daywell reports a sync or monitoring error, tap Retry. After revoking and restoring Screen Time access, choose your apps again if prompted.

Can I use an app during a block?

If you have passes left, tap Temporary Pass in Daywell or on the restriction screen. The block's settings determine how long you can use the app. The pass ends when it expires or the block ends.

The pass button disappears when you run out. Workout restrictions use the rest timer. Log the next set to start another rest. Finish the workout, tap Reset Session, or turn off the rest timer to end workout restrictions.

Why is a restriction still active after I edit or delete a block?

Active blocks keep their scheduled end and pass rules. Editing or deleting a block changes its future repeats. To end an active block early, turn it off while it's still listed and enter the displayed confirmation code.

If you already deleted the block, it runs until its original end. You can still use any remaining passes.

How does Morning Mode work?

Enable Morning Mode on a sleep block. After the block ends, usage of the selected apps counts toward a shared allowance. Once that allowance is used up, the apps are restricted for one break. Adjust both durations in Sleep settings.

Morning Mode uses the remaining passes from that sleep block. If you used the first ten-minute pass during the sleep block, the next pass in the default setup is five minutes. Each new sleep block starts with a fresh allowance.

How do I start a focus session?

After allowing Screen Time access, open Focus, choose one app, and set a duration. The selected app and your allowed apps stay available during the session. To end early, return to Focus and enter the confirmation code shown there.

Does Daywell track health data or sleep?

You log sets manually and can time your rest between them. Daywell doesn't read Apple Health data or measure actual sleep. Your settings and workout progress stay on your device.

How do I revoke access or delete my data?

In iOS Settings → Screen Time, find the apps with Screen Time access and revoke Daywell's permission. The menu name can vary by OS version.

To remove local data, delete the app and its data. Offload App may keep documents and data. Use Apple's backup settings to manage copies in backups. See Data Retention and Deletion for details.

Need More Help?

Include your device model, OS version, Daywell version, and the steps that led to the issue. Cover private information in any screenshots.
